# Music Store SQL Data Analysis Project
📌 Project Overview

This project focuses on analyzing a digital music store database using SQL.
The goal of this project is to practice real-world SQL querying skills by solving business-related problems such as customer analysis, sales trends, top-performing artists, genre popularity, and revenue insights.

The database contains information about:

Customers
Employees
Artists & Albums
Tracks & Genres
Invoices & Sales
Playlists
